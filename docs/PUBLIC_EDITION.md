# Édition publique — 30 septembre 2026

Ce dépôt contient uniquement l’édition Apache-2.0. La publicité, le consentement
publicitaire, l’abonnement, leur serveur, leurs configurations et leurs tests
ont été sortis de l’arbre public. Le titulaire a autorisé le retrait de ces
composants de l’historique récent précédemment publié.

Les fichiers partagés ont été adaptés pour fonctionner directement sans ces
composants. Les fonctions métier, les protections de publication/purge et les
notices tierces obligatoires sont conservées. La compilation refuse un mode
commercial. Le contrôle d’absence des SDK examine aussi les APK réellement bâtis.

Aucune clé AI Studio au format Google connu n’a été trouvée dans les fichiers
publics ou l’historique textuel Git accessible pendant ce contrôle. Ce constat
ne prouve pas une révocation chez le fournisseur.

Les reçus de travail et les copies vérifiées sont conservés localement, hors
des fichiers produit. Les preuves des releases publiées gardent leur portée
historique ; leur code et leurs binaires ne deviennent pas qualifiés par une
nouvelle compilation.
